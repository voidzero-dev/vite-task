# flag_placement

## `vt run args --dry-run`

After the task name, `--dry-run` is passed to the task, which runs.

```
$ vtt print --dry-run ⊘ cache disabled
--dry-run
```

## `vt run --dry-run`

Without a task, there is nothing to preview.

**Exit code:** 1

```
error: No task specifier provided for 'run' command
```
