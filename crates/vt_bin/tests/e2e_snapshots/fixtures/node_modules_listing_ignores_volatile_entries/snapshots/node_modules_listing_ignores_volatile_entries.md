# node_modules_listing_ignores_volatile_entries

A task walks `node_modules`. pnpm's `.pnpm-workspace-state-*.json` and Vite's `.vite-temp` appearing or disappearing there don't invalidate the cache, while a real package entry added to `node_modules` still causes a cache miss.

## `vtt mkdir -p node_modules/real-pkg`

seed a real package under node_modules

```
```

## `vtt write-file node_modules/.pnpm-workspace-state-v1.json {}`

pnpm workspace state file exists before the first run

```
```

## `vt run list`

first run: cache miss

```
$ vtt fs walk node_modules write out.txt listed
```

## `vtt rm node_modules/.pnpm-workspace-state-v1.json`

pnpm workspace state file is removed

```
```

## `vtt write-file node_modules/.vite-temp/vite.config.ts.timestamp-1.mjs 'export default {}'`

Vite creates its transient config temp folder and file

```
```

## `vt run list`

cache hit despite volatile entries appearing and disappearing

```
$ vtt fs walk node_modules write out.txt listed ◉ cache hit, replaying

---
vt run: cache hit.
```

## `vtt write-file node_modules/.pnpm-workspace-state-v2.json {}`

pnpm writes a workspace state file

```
```

## `vtt rm -rf node_modules/.vite-temp`

Vite temp folder is removed

```
```

## `vt run list`

cache hit again

```
$ vtt fs walk node_modules write out.txt listed ◉ cache hit, replaying

---
vt run: cache hit.
```

## `vtt mkdir -p node_modules/another-pkg`

a real package appears in node_modules

```
```

## `vt run list`

cache miss for the real package

```
$ vtt fs walk node_modules write out.txt listed ○ cache miss: 'another-pkg' added in 'node_modules', executing
```
